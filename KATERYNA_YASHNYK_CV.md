OctoMind is a productivity and idea-generation application designed for people with multiple interests, skills, and areas of focus.

The core concept allows users to create separate **Minds** representing different interests or areas of life and, in future development, combine two or more Minds to discover new activities, projects, and connections between their interests.

I am developing the backend architecture and API while also designing the product's mobile UX/UI.

### Current Backend Implementation

- REST API built with Java and Spring Boot.
- Feature-based backend architecture using controllers, services, repositories, entities, and DTOs.
- User registration and login.
- Password hashing with BCrypt.
- JWT-based authentication and authorization.
- Protected API endpoints with Spring Security.
- PostgreSQL persistence using Spring Data JPA and Hibernate.
- Request validation with Jakarta Bean Validation.
- Centralized exception handling and structured API error responses.
- User ownership validation for protected resources.
- Mind creation, retrieval, updating, archiving, and restoring.
- Active and archived Mind filtering.
- Unit testing with JUnit and Mockito.
- Controller testing with MockMvc.
- Automated API regression testing with Insomnia.
- Dockerized PostgreSQL development environment.
- Git/GitHub version control with incremental feature-based development.

### Planned Architecture

The next major feature is **Mind Combination**, allowing users to combine two or more interests.

For example:

`Spanish + Video Creation → Creating videos in Spanish`

Users will be able to select Minds manually or generate random combinations for inspiration.

The combination engine is planned behind a separate architectural boundary so different generation strategies can be implemented over time, including:

- Rule-based generation
- Custom algorithms
- AI-powered generation
- Hybrid approaches

This design will allow the generation mechanism to evolve independently and potentially be extracted into a separate service in the future.

Alongside backend development, I design the **mobile UX/UI in Figma**, including application structure, user flows, interfaces, and product concepts.
