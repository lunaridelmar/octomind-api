# 🐙 OctoMind

OctoMind is a personal productivity and life-management application built around the idea that our lives consist of many different areas competing for our attention.

The goal is to help users organize these areas, track what matters to them, and manage their tasks and goals without feeling overwhelmed.

## 💡 The Idea

Each user has their own OctoMind, where different parts of their life can be represented and managed separately while still being connected in one place.

The project is currently in active development.

## 🛠 Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Docker
- JWT authentication
